# Camila Gonzalez — Dashboard

A personal data dashboard built from scratch in HTML, CSS, and JavaScript
for WRIT 40363. It brings the weather, quotes, and task list
together in a light or dark theme.

**Live site:**
https://gonzcamila.github.io/dashboard/

## Built with

- Semantic HTML
- CSS with design tokens, Grid, and a dark/light theme
- JavaScript with fetch() for the weather and quote data
- localStorage for tasks and the saved theme
- GitHub Desktop and GitHub Pages

## Notes

The accent color and font pairing were chosen in Lab 10.5. for project 1 ( personal portfolio)Contrast
was verified against WCAG AA.
